## Run locally
No build tools or dependencies required:
```bash
python3 -m http.server 8000
```
Open http://localhost:8000 or open `index.html` directly.

## Interactions
- Use the chevron button to collapse/expand the sidebar.
- Select Home, About, Services or Contact to update the content panel.
- Copy buttons copy the displayed code snippets where clipboard access is allowed.

## Source fidelity
